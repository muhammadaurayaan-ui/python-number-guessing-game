PYTHON NUMBER GUESSING GAME
A beginner-friend Python game where the player guesses a randomly generated number.

HOW THE GAME WORKS??
-The computer chooses a random number
-The player has limited attempts to guess the number 
-Hints are given (too high / too low)
-The correct number is revealed if the player fails to guess it

FEATURES
-Random number generation
-Attempt limit
-Input validations
-Clear user messages

WHAT I LEARNED
-Conditional statements
-User input handling
-Using the random module
